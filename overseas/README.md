# overseas/ — 海外ポッドキャストのコーナー用の素材置き場

毎朝の番組に「海外ポッドキャストのコーナー」を作るための素材を置く場所です。

- ファイル名は `YYYY-MM-DD.json`（日本時間の日付）
- 中身は「海外Podcast朝刊」の**1本目**を機械的に抜き出したもの
- 置くのは Mac mini 側の `05_SNS/04_その他/46_20260715海外podcast/scripts/export_to_podcast.py`
- 読むのは `src/overseas.py`（朝6時のワークフローから呼ばれる）

**当日分のファイルが無い日は、コーナーごと消えて従来どおりの番組になります**
（朝刊が「新着なし」の日や、Mac miniが止まっていた日でも放送は止まりません）。

## 形式

```json
{
  "date": "2026-09-10",
  "title": "エピソードのタイトル",
  "show": "番組名",
  "url": "https://www.youtube.com/watch?v=...",
  "summary": ["3行まとめ1", "3行まとめ2", "3行まとめ3"],
  "points": ["要点1", "要点2"],
  "actions": ["今日からできること1"]
}
```

`title` と `summary` が空のときは、素材として使わずコーナーを出しません。
